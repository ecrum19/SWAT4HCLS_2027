\section{RQ3: integration with external data}
\subsection{Method}
\label{sec:m-rq3}

RQ3 asks which externally flagged alterations have sufficient sample depth and which source observations support the answer.
The experiment has three inputs, all in \href{https://github.com/ecrum19/SWAT4HCLS_2027/tree/main/RQ3}{\path{RQ3/inputs/}} of the experimental repository.
The first is a VCF fixture, \path{local-alleles-v4.5.vcf}, of four synthetic sites for one sample column, each site written twice: with local-allele (\texttt{LAA}, \texttt{LAD}, \texttt{LPL}) and with global (\texttt{AD}, \texttt{PL}) fields.
The second, \path{annotations.ttl}, is a separately authored snapshot of five invented, flagged alterations that shares no identifiers with the fixture.
The third is the query, \path{local-allele-evidence.rq}, excerpted in Listing~\ref{lst:localallele}.
VCF-RDFizer 3.0.3~\cite{vcfrConverter2026} converts the fixture in the expanded profile, and the query runs over that graph together with the snapshot, joining on contig, position, reference allele, and alternate allele, then retrieving supporting depth through \term{forAllele}.
This assumes the same reference assembly, unchecked against the VCF reference declaration, and identical as-written alleles without normalization or VRS identification.
The sample identifies a VCF column, not a patient.

\begin{lstlisting}[float=htbp,caption={
Graph-pattern excerpt from the \term{WHERE} clause of \texttt{local-allele-evidence.rq}. 
Prefix declarations, \term{SELECT}, filtering, and provenance retrieval are omitted.},label={lst:localallele}]
# 1. the flagged alteration, from the external annotation snapshot
?annotation a ex:FlaggedAlteration ; ex:contig ?contig ; ex:position ?position ;
            ex:referenceAllele ?ref ; ex:alternateAllele ?alt .
# 2. the same alteration as written in the VCF file
?record vcfc:chrom ?contig ; vcfc:pos ?position ; vcfc:ref ?ref ;
        vcfc:hasCall ?call ; vcfc:hasAltAllele ?altAllele .
?altAllele vcfc:alleleValue ?alt .
# 3. that sample's LAD value, and the declaration giving LAD's cardinality
?call vcfc:hasSampleCall/vcfc:hasFormatValue ?field .
?field vcfc:declaredBy [ vcfc:fieldId "LAD" ; vcfc:fieldNumber ?number ] ;
       vcfc:hasValueItem ?item .
# 4. the depth for THIS allele, via the sample's own local allele set
?item vcfc:forAllele ?altAllele ; vcfc:itemValue ?depth .
\end{lstlisting}

The query keeps only depths of at least 20 (\texttt{LAD >= 20}), distinguishing correct allele-depth joins from positional misreading while retaining source context.
Expected rows, authored before execution, are compared across eight answer fields, with a ninth, the source file, checked against the converted input path.
Each of the three excluded alterations is checked individually.
The example concerns only \texttt{Number=LR} \texttt{LAD}.
The snapshot's annotations have no biological meaning and are stored with the experiment so that every run returns the same answer.

\subsection{Results}
\label{sec:integration}

On the fixture, the query returns the two expected alterations and retains the correct file, record, sample, and FORMAT declaration context.

To explain the result without a further listing, Table~\ref{tab:local-allele-example} and Figure~\ref{fig:model} use Listing~\ref{lst:vcf-example} rather than the experimental fixture.
In Listing~\ref{lst:vcf-example} lines 8--9 are simplified versions of the fixture's first two local-allele records, keeping the positions, reference alleles, and the local alleles and depths that the joins use, with \texttt{S1} representing the fixture's sample.
\stepmark{A} For \texttt{chr1:1~G>C}, the four location and allele values listed in the annotation (\href{https://github.com/ecrum19/SWAT4HCLS_2027/blob/main/long_revised/examples/annotations.ttl}{\path{long_revised/examples/annotations.ttl}}) identify the record's "C" allele, and \term{forAllele} leads to depth 30 (Figure~\ref{fig:model}).
\stepmark{B} For \texttt{chr1:1~G>A}, the same location matches, but no \texttt{LAD} value of \texttt{S1} is linked to "A", so the query excludes the alteration.
\texttt{S2} is not considered in this representative example.
